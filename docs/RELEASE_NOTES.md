# V20.2 Release Notes

## Development base

V20.2 is built on the confirmed working V19.1/V20/V20.1 standalone gameplay
baseline.

## Stage choreography

The stage now escalates through:

**OLD CITY → NIGHT MARKET → DUNE CROSSING → COMMAND PERIMETER**

Combat density is increased through rooftop threats, air-raider entrances,
multi-level attacks and short reinforcement bursts.

## Rescue loop

Rescued civilians now visibly exit and create reward drops instead of only
changing a counter.

Reward sequence:

**HMG → Grenades → Shotgun**

## Vertical combat

The player can attack elevated enemies and can fire downward while airborne.

## Originality boundary

Classic arcade screenshots supplied during development were used only to study
pacing, density, verticality, rescue/reward rhythm and encounter choreography.

The repository does not include third-party commercial game source code,
sprites, music, characters, vehicles, stage artwork or UI assets.
